# RussiCaptor Excel Schema

One exercise = one Excel workbook.

Editable demo template:

`outputs/russicaptor-template/Exercise_Demo.xlsx`

The `Instructions` sheet contains editing guidance, allowed code values, QR examples,
and automatic row-count checks. The remaining sheets are imported by the app.

Example:

Exercise_Demo.xlsx

Sheets:
- Patients
- Locations
- InterventionOptions
- Interventions
- MedicationOptions
- MedicationAdministrations
- Vitals
- Questions
- Labs
- Imaging
- Notes
- Orders

Timeline is generated by the app and is not edited in Excel.

## Vitals

Each patient must have at least one baseline row at `ExerciseMinute` 0. Later
scenario rows are revealed automatically as the exercise clock reaches their
minute. Measurements entered by a CM in the app use `Source` = `manual`.

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Related patient |
| VitalId | Unique vital-sign measurement id |
| ExerciseMinute | Exercise minute when the scenario value becomes visible |
| RecordedAt | Optional display time |
| RecordedBy | Optional recorder name or user id |
| Source | scenario / manual |
| HeartRate | Heart rate, beats/min |
| SystolicBP | Systolic blood pressure, mmHg |
| DiastolicBP | Diastolic blood pressure, mmHg |
| RespiratoryRate | Respiratory rate, breaths/min |
| SpO2 | Oxygen saturation, % |
| Temperature | Body temperature, °C |
| GCS | Glasgow Coma Scale, 3–15 |
| BloodGlucose | Optional blood glucose, mmol/L |
| EtCO2 | Optional end-tidal CO₂, mmHg |
| PainScore | Optional pain score, 0–10 |
