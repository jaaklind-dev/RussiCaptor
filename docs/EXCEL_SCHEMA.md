# RussiCaptor Excel Schema

One exercise = one Excel workbook.

Example:

Exercise_Demo.xlsx

Sheets:
- Patients
- Questions
- Labs
- Imaging
- Notes
- Orders

Timeline is generated by the app and is not edited in Excel.

---

## Patients

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Internal patient id, e.g. PT-001 |
| NationalId | QR code value / isikukood |
| Name | Patient name |
| Triage | P1 / P2 / P3 / P4 |
| Status | Active / Incoming / Transferred / Completed |
| Location | Current location |
| LastSeen | Last update time |
| MistMechanism | MIST M |
| MistInjuries | MIST I |
| MistSigns | MIST S |
| MistTreatment | MIST T |

---

## Questions

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Related patient |
| QuestionId | Unique question id |
| Category | Question category |
| Order | Display order |
| Prompt | Question shown to CM |
| Answer | Answer revealed by CM |
| Visibility | hidden / available / revealed |

---

## Labs

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Related patient |
| LabId | Unique lab result id |
| Panel | ABG / CBC / Chemistry etc |
| Name | pH / pCO2 / WBC etc |
| Value | Result value |
| Unit | Unit |
| ReferenceRange | Reference range |
| Status | processing / available / viewed |
| Visibility | hidden / available / revealed |
| ReleasedAt | Time result became available |

---

## Imaging

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Related patient |
| ImagingId | Unique imaging id |
| Modality | XR / CT / US / ECG / OTHER |
| Title | Study title |
| Report | Text report |
| Attachment | File path or OneDrive reference |
| Status | processing / available / viewed |
| Visibility | hidden / available / revealed |

## Notes

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Related patient |
| NoteId | Unique note id |
| Author | CM / EXCON / System |
| Text | Note content |
| CreatedAt | Timestamp |
| Visibility | hidden / available / revealed |

## Orders

| Column | Description |
|---|---|
| ExerciseId | Exercise identifier |
| PatientId | Related patient |
| OrderId | Unique order id |
| Type | lab / imaging / consult / treatment |
| Name | CBC / CT Head / Surgery consult etc |
| Status | requested / processing / completed / cancelled |
| RequestedBy | User id |
| CreatedAt | Timestamp |
| CompletedAt | Timestamp |
